# AWS Serverless AI Agent

This project demonstrates a production-style AWS serverless application using
Lambda, API Gateway, and Infrastructure as Code (Terraform).

## Architecture
- AWS Lambda (Python)
- API Gateway (HTTP API)
- IAM roles with least-privilege
- Terraform for infrastructure provisioning

## Project Structure
/infra  - Terraform infrastructure files  
/src    - Python Lambda source code  
/docs   - Architecture diagrams and screenshots
